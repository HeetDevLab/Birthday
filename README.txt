HEET SHAH PORTFOLIO — VERSION 3

This is a static HTML/CSS/JavaScript portfolio designed for GitHub Pages.

FILES
- index.html
- style.css
- script.js
- favicon.svg

IMPORTANT: KEEP YOUR EXISTING ASSETS FOLDER
The current portfolio links to these existing files:
- assets/profile.png
- assets/Heet_Shah_Resume.pdf

The supplied source package intentionally does not overwrite or replace your existing profile photo or resume. When updating the repository, keep the current assets/ folder and its contents unchanged. If your repo already has other asset files, leave those in place too.

HOW TO UPDATE GITHUB PAGES
1. Back up your current portfolio repository.
2. Extract this ZIP.
3. Upload/replace index.html and style.css in the portfolio repository root.
4. Upload script.js and favicon.svg to the same root.
5. Do not delete the existing assets/ folder.
6. Commit the changes and wait for GitHub Pages to publish.
